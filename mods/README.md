# Drover mods

One folder per mod (`drover-*`), the `drover` layout in `_layouts/`, and the shared library in `_lib/` (copied into every mod by `install.sh`; edit `_lib` only).

- What each mod does, its settings and what it needs: [docs/README.md](../docs/README.md#the-mods).
- Install and update: [docs/install.md](../docs/install.md). Settings: [docs/configuration.md](../docs/configuration.md).
- Default agents, squads and the `drover` CLI: [docs/agents.md](../docs/agents.md).
